## 4. Google Drive Upload & Submission Instructions

1. Open **Google Drive** (`https://drive.google.com`).
2. Click **New ➔ Folder Upload** (or create a new folder titled `Gujarat_Police_CCTV_Hackathon_TEAM_CIPHER_Screenshots`).
3. Upload the entire `Screenshots/` directory (both `Public_Citizen_Portal` and `Admin_Operations_Console`).
4. Right-click the folder in Google Drive ➔ Click **Share**.
5. Set General Access to **"Anyone with the link can view"**.
6. Copy the shareable link and paste it into **Question 29** of the Google Form.
